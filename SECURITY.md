# Политика безопасности

Если вы обнаружили уязвимость в XWDTT, пожалуйста, сообщите о ней так, чтобы проблема не стала публичной до исправления:

- предпочтительно — **Security Advisory**: страница репозитория → *Security* → *Report a vulnerability*;
- иначе — Issue с заголовком `[SECURITY]:` (без деталей эксплуатации в открытом виде, укажите контакты для связи).

Ответ обычно появляется в течение нескольких дней. Исправления выпускаются в новых тегах `v*` через автоматический релиз.

Публичные Issues подходят для обычных ошибок — используйте шаблон «Сообщить об ошибке» и прикладывайте вывод `xwdtt report`.
